One line per non-obvious finding, dead end, or rejected approach, written BEFORE acting on it (README §5.4b).

- **Read `04 §2` in full before writing anything this time.** M0-T3-a was authored against `03 §1` alone and missed `04 §1`'s namespace, crosscheck segregation, `get()` accessor and required `unit` — four gaps, one of them functional (`11 §4`'s static misuse grep had nothing to grep). Fixed on `fix/M0-T3-a-04-conformance` before starting here, so `ns::rng` does not compound a wrong `ns::consts`.

- **`normal_f()` must NOT cache its second Box–Muller deviate.** The obvious implementation generates two normals per pair of uniforms and caches one. But `04 §2` says the resumable state is exactly `(ctr, sub)` and `03 §8 §2` serialises exactly those two. A cached deviate is a third piece of state; a checkpoint taken between the two calls would resume with it lost, and D9's kill→resume→bit-identical test would fail intermittently — the worst possible failure signature. Generating two uniforms and discarding one deviate costs a `cos` and keeps the state honest.

- **The project-local KAT must not be self-generated.** `04 §2` wants the first 16 `uniform_f()` of `Stream(0,0)` frozen in `tests/unit/rng_kat.inl`. Recording whatever my C++ happens to emit proves only that it is self-consistent. Instead: an independent Philox in Python (`tools/verify/rng_kat_gen.py`) that first reproduces the three published Random123 vectors — external ground truth — and only then emits the `.inl`. Two independent implementations agreeing on the wrapper layout is evidence; one implementation agreeing with itself is not.

- **`splitmix64` is ambiguous in `04 §2`'s fork formula.** Some references define it as the finalizer alone, others include the `x += 0x9E3779B97F4A7C15` increment first. `04 §2` writes `splitmix64(<expr>)` where the expression already contains a golden-ratio multiple, so both readings are defensible. Taking the full standard variant (increment + two xor-multiply rounds + final xorshift), documenting it in the header, and freezing `fork(42, 1000, 3)` as a KAT — which is what makes the choice normative rather than incidental.
