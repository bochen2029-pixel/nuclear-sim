- **Design — PUCT over a k-d box tree (continuous "node-discretize then refine"):**
  - Node = a hyperrectangle [lo,hi]/axis + {visits N, value-sum W, children}. Root = the full
    axis box. A node SPLITS its longest axis at the midpoint → 2 child half-boxes (binary k-d).
  - `next()`: descend from root — if the node has an un-added split-child AND progressive widening
    allows (children < 1+floor(pw_k·N^pw_alpha), capped at 2) AND depth<max_depth → EXPAND (add the
    next child, return its box CENTER as the ParamSet); else if it has children → SELECT the child
    maximizing PUCT `Q + c·sqrt(N_parent)/(1+N_child)` and recurse; else (leaf at max depth) return
    its center. Record the root→leaf `last_path_`.
  - `report(params, tally)`: score = `-|tally.yield_kt − center| / half_width` (BandCenter; higher
    = closer to the calibrate band center). Backprop: each node in `last_path_` gets N+=1, W+=score.
    Assumes next→report ALTERNATION (the sweep/run loop does this; the DoD test does too).
  - Points are box CENTERS → deterministic + reproducible (no RNG); refinement happens because
    high-Q regions get re-selected → deeper splits → finer centers near the optimum.
- **make_sampler("mcts")** (builtin.cpp): construct `MctsSampler(manifest)`; REQUIRE the objective
  is calibrate with a target band (else SweepError — BandCenter needs a center). score_kind()=
  BandCenter (so the existing OptimizeExtremum-reject guard passes). Pedagogical+mcts is already
  loader-rejected (pedagogical ⇒ sampler=="grid"), so make_sampler never sees it.
- **Tests (nukefarm.):** (1) converges-faster-than-random: a synthetic landscape yield(x,y) =

  TallyResult{yield_kt=landscape}) for mcts vs random; assert mcts's best |yield−center| <
  random's (mcts concentrates near the optimum). Deterministic (no RNG in mcts; random sampler is
  seeded). (2) mcts requires a calibrate target band (sensitivity → SweepError). (3) pedagogical +
  mcts is rejected at PARSE (loader). (Grid/lhs/random unaffected.)
