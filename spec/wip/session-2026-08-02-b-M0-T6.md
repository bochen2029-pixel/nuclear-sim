The GPU rows of `11 §3`'s matrix are explicitly "self-hosted/cloud GPU (on demand, M4+)". Rejected pulling `nvidia/cuda:13.1-devel-ubuntu22.04` for the linux job: `12 §3` says that tag must be VERIFIED at M5-T5 before use, and building CI on an unverified tag would make the workflow fail for a reason unrelated to the code.

- **The Linux job is the first time this code meets gcc, and `-Wall -Wextra -Werror` is on.** MSVC `/W4` does not warn on `size_t == int`, gcc's `-Wsign-compare` does. `src/core/xs/xs.cpp` compares `matrix.size()` and `bounds.size()` against `kGroups` (an `int`, because `04 §3`'s `groups()` returns `int`), and several loops run `std::size_t` against it. Fixing those before the first CI run rather than discovering them one red build at a time.
