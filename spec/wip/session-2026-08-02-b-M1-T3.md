- **ADR-013 is the trap here.** The eigen solver MUST return `k_eff` on TOTAL ν̄ — the benchmark-comparable quantity — and MUST NOT return a β-corrected k. `beta_eff` is returned alongside so `k_prompt = k_eff·(1−β_eff)` can be derived exactly once, downstream, by the kinetics. A solver that returns k_prompt would be off by ~650 pcm on a U-235 system, which is larger than G0a's entire tolerance and still looks entirely plausible.
- **Watch for any 1σ or 2σ acceptance threshold in this DoD** — M1-T2 established that such a criterion has a 32%/4.6% false-failure rate and cannot be fixed with more samples. `05 §2`'s stated checks are 3σ and a ratio band, which are fine.
