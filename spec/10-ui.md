# 10 — UI Spec (nukestudio panels)

Widgets are generated from the scenario schema + `[ui."<dotted.path>"]` annotations (`03 §4`, MAJ-25): `range` is ALWAYS in schema units; `display_unit`/`display_scale` affect presentation only; a field with no `[ui.…]` entry gets no widget. The table below is generated from those annotations — it is documentation, not a second source of truth. A test (`11 §4`) asserts every row resolves to a `[ui.…]` entry + real schema field, and that defaults lie inside ranges.

**Derived thickness rule:** `layers.<id>.thickness_cm` is a UI-derived control that writes that layer's `r_outer_cm` and shifts all outer layers by the same delta; it is not a schema field and never appears in a scenario file. Material/xs rows write through the `[overrides]` mechanism (03 §4) and mark the run non-canonical.

## Panels

1. **Parameters** — the table above; status badge (P/D/R/S) on every value; counterfactual values raise the persistent **non-canonical badge** (`00 §2`); beyond-envelope values (e.g. compression > 2.5×) raise an "extrapolation beyond public data" badge.
2. **Geometry** — 3D cutaway of LayerStack with layer labels; exploded-view toggle; free clip plane (point + normal) applied to the shells and the Fields view alike (`09 §2`, ADR-018); detonator toggle/delay grid over the lens assembly, binding `lenses.detonators` (M6 geometry, ADR-018).
3. **Criticality** — live k gauge (k>1 zone, quench-phase marker per E6), Rossi-α readout (E3c), critical-mass-equivalent readout (label: "public-band estimate").
4. **Burst** — log₁₀ neutron population vs time (log-y), cumulative yield with σ, per-generation fissions, pre/post-peak split.
5. **Fields** — volumetric view per `09-rendering.md`; channel selector (T / ρ / fission_rate / shock). Temperature values carry a "visualization mapping, not physics tally" badge (C-20).
6. **Timeline** — D6 timebase switch (ns/µs/ms/s), play/pause/step-generation, scrub (paused runs only); event markers at computed state transitions — HE initiation (t=0), shock convergence, prompt-critical crossing (k_prompt ≥ 1, ADR-013), peak power, quench (E6) — derived from kinetics/hydro state, never hand-placed (ADR-018).

## Rules

- Burn-up display MUST show Pu burn-up and tamper yield fraction as separate labeled numbers (`00 §3.5`).
- No false precision: yield shown with its σ and the public band (e.g. "20.0 ± 0.6 kt (public band 16.6–26.8)").
- Shakes are a DISPLAY unit only (00 §4); all schema values are seconds.
- Export button writes the exact reproducing scenario TOML (gate G5).
- Gate evidence can only come from canonical runs; the studio MUST refuse to write a gate report from a non-canonical run.
- Any non-default `lenses.detonators` configuration marks the run `non_canonical` (same discipline as `[overrides]`); `enable = false` extrapolates the c_a model beyond its calibrated jitter envelope and raises the beyond-envelope badge (ADR-005/ADR-018).
