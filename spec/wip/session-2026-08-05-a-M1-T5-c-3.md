`|k_ref − k_gpu| ≤ 3·√(σ_ref²+σ_gpu²)` AND `≤ C-932 (100 pcm)`. Closes the k-equivalence core of
**M4-T3-b** (the formal G0c gate). Runs cheap now (the c-2 gpu backend + a modest ref batch).
